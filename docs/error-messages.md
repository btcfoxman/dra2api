# 任务错误返回规则

`GET /v1/videos/{id}`、Responses、兼容视频任务接口及管理端使用同一套错误分类。管理端列表和详情通过 `public_error_message` 展示统一提示，原始 `error_message` 与上游审计记录仍保留。

| 错误类型 | 默认提示 |
| --- | --- |
| 参考图包含真人 | 参考图片中检测到可能存在真人，暂不支持，请更换图片后重试~ |
| 通用内容审核 | 检测到内容有敏感或违规情况，请修改后重试~ |
| 文本审核 | 检测到文本有敏感或违规内容，请修改后重试~ |
| 输入图片审核 | 检测到图片有敏感或违规内容，请修改后重试~ |
| 输入视频审核 | 检测到视频有敏感或违规内容，请修改后重试~ |
| 生成视频审核 | 生成的视频内容违规，请修改描述后重试~ |
| 上游队列/并发限额 | 上游队列排队限额，请稍后再试~ |
| 队列服务中断 | 队列排队服务中断，请稍后再试~ |
| 素材时长 | 素材时长不支持，请修改后再试~ |
| 素材数量/大小超限 | 素材超限，请修改后再试~ |
| 素材格式 | 素材格式不支持，请修改后再试~ |
| 素材下载 | 素材下载失败，请检查素材链接后重试~ |
| 上游要求外链素材 | 素材仅支持外链，暂不支持文件流、Base64等~ |
| 其他失败 | 生成失败，请重试~ |

已确认的退款条件：本任务 `raw_status.billing.status == "refunded"`，或存在 `raw_status.billing.refunded_at`。仅有失败状态、费用预留释放或 `refund_requested_at` 均不表示退款完成。

确认退款后，审核类提示在结尾添加 `，积分已返还~`；其他未知生成失败使用 `生成失败，积分已返还，请重试~`。队列和素材提示保持表中内容。返回文案不发起退款，也不改变账务记录。

真人审核分类优先于通用内容审核，不能把真人审核失败归为队列限额。匹配对象仅为错误代码及错误信息，不扫描用户提示词。公开的 `error.code` 保持原值，不影响调用方原有的失败处理。

## 素材下载

1. 新建不读取环境代理的直连会话，完整下载素材。
2. 若发生连接、TLS、HTTP 错误或传输中断，且账号配置了代理，则通过账号代理重新下载一次。丢弃失败尝试的部分内容。
3. 没有代理或两个路径均失败时，返回素材下载错误；大小等本地校验失败直接拒绝。

管理端审计 `upstream_response.protocol.media_download_error` 记录失败素材的总序号、类型、尝试路径、来源主机、异常类型及 HTTP 状态，不保存 URL 查询参数或代理凭据。该改动只影响源素材下载，Drama.Land 的认证、上传及生成仍使用账号代理。

Base64 支持保持现有行为。“仅支持外链”的文案只用于真实发生对应拒绝的情况，不表示本服务关闭了 Base64 输入。
