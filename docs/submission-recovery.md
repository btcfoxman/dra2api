# 提交中断与素材上传重试

## 报价批准后，命令未执行

Drama.Land 的报价批准不等于视频已经提交。2026-09-16 的实际操作记录显示：

1. 首次报价批准后，带英文对白的命令发生 shell 引号解析错误，退出码为 2。
2. 上游改用 `--prompt=@file:/workspace/prompt.txt`，重新请求相同参数和积分的报价。
3. 旧逻辑因已有 `approved_id` 拒绝第二次报价，上游暂停等待用户确认。
4. 网站发送 `POST /api/pi/prompt`（`text` 为“确认提交”），再批准新报价，返回唯一的 `job_ref`，最终生成成功。

服务使用同项目的 `GET /api/pi/history` 获取工具调用和结果。只有明确的 shell 解析错误、没有其他未知生成调用、没有计费记录，且重新查询仍无任务时，才允许继续。同项目最多修复两次报价；修正后的报价必须通过上游预检，符合原模型、时长、分辨率、比例和素材，且积分不高于原报价及调用者的 `max_credits`。

上游已暂停时，服务会发送一次保持原请求的确认消息，再处理报价。确认消息和审批意图均先持久化，再执行请求；网络响应丢失和进程重启不会重复发送同一操作。旧版本由服务拒绝的报价可通过历史工具结果识别。

已有视频任务、未知工具错误、缺少执行结果、已有计费记录或达到修复上限时，不批准新的付费生成。上游声称“没有扣费”或查询暂未发现任务，均不足以单独授权续交。审核拒绝、供应商失败及其他需要改变内容的情况不适用此规则。

管理端重试中断任务会继续使用原项目；若用户已在网站完成提交，服务查询并接收该项目的结果。

新项目要求上游将完整提示词保存为 UTF-8 文件，再通过 `--prompt=@file:` 提交，以减少引号导致的命令解析失败。

## 素材对象上传

图片类型以下载到的实际文件内容为准。部分素材站点会把正常 PNG 返回为 `application/octet-stream`，而调用中的 `image-1` 等展示名没有扩展名；不能据此认定图片格式错误。服务校验图片结构，识别实际 MIME 类型、宽高，并补全或修正上传文件名的扩展名。签名请求、对象 PUT 和项目参考素材使用相同的实际类型，图片字节保持不变，不转码或压缩。

缺失、通用或错误的响应头不会阻止有效图片上传。无法识别的图片、损坏文件、HTML/JSON 错误响应在签名前拒绝，返回 `MEDIA_FORMAT_UNSUPPORTED`；任务审计的 `media_validation_error` 记录素材序号、原始响应类型和异常类型。成功上传的审计字段 `source_content_type` 保留源站声明类型，`content_type` 保存实际上传类型。

音频和视频先由 `ffprobe` 读取已下载文件的实际容器和流，再确定 MIME、文件名和时长。源站返回 `application/octet-stream` 或使用 `audio-1`、`video-1` 等无后缀展示名时，也能识别有效素材。例如 MP3 按 `audio/mpeg` 上传，音频 MP4/M4A 按 `audio/mp4` 上传；原文件不转码、不裁剪。MP3/M4A 中的封面图片不算视频流；含实际视频画面的文件不能直接伪装为音频引用。

音视频检测仅访问下载后的临时文件，拒绝播放列表或外部流引用。未识别的容器、错误页、损坏文件和类型不匹配返回 `MEDIA_FORMAT_UNSUPPORTED`；无有效时长返回 `MEDIA_DURATION_UNSUPPORTED`。模型对参考音视频总时长的限制继续使用检测到的真实时长校验。

素材下载完成后，以签名 URL 执行对象存储 `PUT`。遇到连接异常、超时、HTTP 408/425/429 或 5xx 时，使用相同签名 URL 和相同字节重试，不重复下载素材、不重新申请签名，也不创建视频任务。

- 重试次数沿用 `DRA_REQUEST_RETRIES`，默认重试两次，即总计三次尝试。
- 使用指数退避；数字形式的 `Retry-After` 参与等待，上限 30 秒。
- 400/401/403/404/413/415 等明确拒绝立即返回失败。
- 耗尽重试后，管理端任务协议日志的 `media_upload_error` 记录素材序号、类型、每次 HTTP 状态和异常类型，不保存签名 URL 或认证信息。
- 历史终态失败任务不会因部署自动重新生成；管理端可按需重试。

## 验证

自动化测试覆盖解析失败后的报价、暂停续交、同参数约束、已存在任务、任务查询延迟、未知错误、重启及响应丢失，另覆盖上传重试次数、永久拒绝、等待间隔和日志脱敏。真实操作录制与项目历史在私有工作区保存，不提交到公开仓库。
